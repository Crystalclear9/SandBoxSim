# 天气与生态变化

生态内容在真实土地上运行，不使用工程队列、阶段目标、维护额度或完工对照。玩家直接调整地形、水土、林木、资源和天气，世界按自己的时间继续变化。

## 自然地点

泉眼与苇泽涵养附近土壤；古树林保留林地湿度；野果地与花甸随生长周期结果。倒木林隙留下有限木料，尚存的朽木缓慢提高附近肥力。改变中心地形、建造或火灾会影响相应作用。

野果地与花甸的额外食物受湿度、肥力和植被约束，休眠停止额外补充。原有采集、天气、火灾和资源再生仍继续运行。自然地点不会自动升级为库存，也不提供领取奖励的按钮。

## 玩家栽植的生态

从底部“生态”选择花种、野果、苇泽或腐木，直接在土地上放置。每片地块影响周围三格，能够连续栽植与组合；已有道路、建筑和地形高度保留。

植物成熟度随游戏日推进：湿度、肥力与踩踏共同决定恢复速度，适宜环境约八天成形；干旱可能使其回退，休眠期停止生长。近景植株随成熟度逐渐展开，现场手记显示实际状态。新的地块、成熟度及日界进度均保存，载入不会截断为旧版的十五个地点。

野果地在十格内存在成熟度至少一半、湿度不低于四分之一的活跃花甸时，额外结果增加 25%；花甸受损或干枯后这项影响消失。果实仍受自身水土和季节约束，由居民实际采集。新放置腐木提供有限 24 单位木料，原生倒木地点仍为 48 单位；同一活跃地块不会因重复点按补满木料。

该生态层由图形会话中的 `WildPlaces` 管理。纯 HTTP 内核服务保留原有动作集；源码控制器可持有 `WildPlaces`，调用 `Cultivate`、`Advance`、`Encode/Decode` 复现相同的额外生态作用。

## 直接改变条件

工具会立即作用于当前范围。河流与水域改变饮水和通行；地形升降改变地貌；森林、草地和湿地改变资源与栖息环境。雨水、干旱、火灾与动物活动会影响区域，结果可以在地块详情、人口曲线和世界历史中观察。

湿润土壤仍不同于可饮用的水。地表资源、居民携带物、地面堆和仓库存量分别记录；人们能否利用它们取决于位置、路径与自身行为。

自然地点机制见 [自由探索](exploration.md)，内核规则见 [世界系统](world-systems.md)。

## 反复活动与恢复

脚步、采集作业与商队让土地逐渐压实。压实降低资源和植被再生，停止使用后按游戏小时缓慢恢复；它不会自动铺出道路。近景草丛读取压实伏低，显示与真实地表状态共用数据。累积速度和保护范围见 [地形与活动痕迹](terrain-and-traces.md)。
