# 天气与生态变化

生态内容在真实土地上运行，不使用工程队列、阶段目标、维护额度或完工对照。玩家直接调整地形、水土、林木、资源和天气，世界按自己的时间继续变化。

## 自然地点

泉眼与苇泽涵养附近土壤；古树林保留林地湿度；野果地与花甸随生长周期结果。倒木林隙留下有限木料，尚存的朽木缓慢提高附近肥力。改变中心地形、建造或火灾会影响相应作用。

野果地与花甸的额外食物受湿度、肥力和植被约束，休眠停止额外补充。原有采集、天气、火灾和资源再生仍继续运行。自然地点不会自动升级为库存，也不提供领取奖励的按钮。

## 直接改变条件

工具会立即作用于当前范围。河流与水域改变饮水和通行；地形升降改变地貌；森林、草地和湿地改变资源与栖息环境。雨水、干旱、火灾与动物活动会影响区域，结果可以在地块详情、人口曲线和世界历史中观察。

湿润土壤仍不同于可饮用的水。地表资源、居民携带物、地面堆和仓库存量分别记录；人们能否利用它们取决于位置、路径与自身行为。
