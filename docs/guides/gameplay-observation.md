# 观察与界面

界面使用石墨蓝灰控制栏、暖白阅读面板和低饱和青灰选中态。顶部世界、资源与菜单共用一条连续信息栏；底部时间和镜头控制位于同一底栏，中间的浅色工具导航形成视觉焦点。世界铺满窗口，手记按需展开；没有任务栏、住房委托卡片或工程阶段页。

## 人物与土地

人物页以横幅近景肖像、姓名、年龄与职业呈现居民，需求条显示实际状态。决策与性格、关注和改名集中在一行；点击“改名”才展开输入框，命名后收起。资料内容可以整页滚动，关系、物资和个人历史不会被限制在底部的小区域。动作卡显示居民正在做什么、执行阶段与目的地；肖像同步呈现这个实际行为。短暂的采集完成后会补足一次拿取或工具动作，状态卡标记“动作收尾”；这不会重复产生资源。人物会眨眼、轻微调整视线。全身观察中的工具握持包含接触后合拢和放回后松手；左右手分别握柄，搬运时物资保持直立。肖像底部“面部 / 手部 / 全身”切换构图；手部视图跟随实际双手位置，方便查看拿取和握柄。左右拖动旋转，上下拖动俯仰，滚轮平滑缩放；双击画面或点击“复位”恢复当前构图，不影响地图镜头。

手记宽度随窗口调整，标题改为紧凑栏，人物肖像保留 256 像素逻辑高度，并以匹配比例的独立视口渲染；资料仍整页滚动。展开观察窗最大为 1200×800 逻辑像素，随窗口收缩。肖像使用带局部阴影的暖色主光和两盏柔和补光，全身构图以有限圆形地台接住脚下阴影；悬停显示操作提示。生命条用灰绿、干渴条用浅蓝、其他需求用暖铜色，危险状态统一转为暖红；所有指标保留名称与百分比。Esc 依次关闭人物观察窗、世界设置、手记；没有展开面板时退出当前工具并收起工具栏。按钮可通过 Tab 获得焦点，悬停与键盘焦点都有可见反馈；世界设置关闭“柔和界面动效”后，过渡立即完成。

近景人物头脸读取 MakeHuman CC0 拓扑与三套形体配方，保留原生皮肤、眼球和发片；眨眼驱动原脸眼睑。远景使用简化模型。衣身与配件仍包含程序构造，具体结构与当前表现边界见 [模型系统](../development/models.md)。

点击肖像底部工具栏的“放大”进入独立人物观察窗。左侧复用当前模型、旋转角度和构图，继续显示实际动作；右侧同步显示行动阶段、两列需求卡片及实际随身物资。资料可滚动，跟随与关注操作固定在下方。顶部可按稳定身份顺序切换上一位、下一位居民，不退出观察窗；底部集中提供聚焦、角度预设、缩放和复位。Esc、“返回手记”或点击遮罩空白处可关闭，回到当前居民的档案。展开会中止地图旧拖拽，后续鼠标操作留在观察窗，Tab / Shift+Tab 也只在窗内可用控件间移动；仅剩一位居民时导航按钮停用并跳过键盘焦点。模拟仍会推进，未聚焦按钮时空格可暂停；聚焦按钮后空格遵循按钮的键盘激活行为。观察窗本身不改变居民、物资或世界状态。

展开时键盘焦点进入模型区域；Tab 长按重复、方向键的控件导航均留在窗内，方向键不移动镜头。返回时恢复此前仍可用的控件焦点。关闭柔和界面动效会同时停止肖像操作提示的淡入淡出，并让缩放与旋转立即到达当前目标。

## 交互反馈

工具菜单采用三列卡片，每个工具同时显示图标、名称与用途短句；分类标题区说明可自由干预，不提供游玩任务。地貌分类容纳完整工具集，面板按行数改变高度。工具面板使用与手记一致的浅色表面；打开工具会收起手记，打开手记也会收起工具，避免 1280 像素窗口里两个面板相互覆盖。当前工具的参数仍保留在左侧。

底部观察、自由干预与手记之间用细分隔区分，悬停说明每类工具的用途；干预参数面板右上的“×”直接结束干预并返回自由观察。下拉菜单、输入框、滚动条和浅色提示框共用主题，保留键盘焦点边线。关闭柔和动效后，按钮与面板立即显示最终状态。

按钮悬停、按下、页签切换、面板展开和数值变化有短暂过渡。设置可关闭柔和界面动效，偏好保存在本机 `user://interface.cfg`；视觉过渡不推进内核、不消耗模拟随机流。

顶部世界信息、资源和菜单在连续栏内分组；时间倍率使用铜色强调，浅色导航与工具使用青灰选中态与细线，悬停提供底色与短暂光带，按下有局部波纹。反馈不移动按钮的点击范围。顶部和底部手记入口同步开合状态，观察入口标示当前观察模式。手记使用暖白面板和深色文字，导航图标为灰青色 16 像素线稿，详情标题和图标随人物、动物或土地选择切换。小地图标出选中位置，悬停显示坐标与定位环，单击可定位。

镜头支持鼠标平移、旋转、俯仰与缩放，小罗盘随真实视角变化。画笔工具下右键拖动仍然旋转视角，Esc 才返回观察。操作见 [玩家手册](player-guide.md)。

## 世界呈现

单击住房后，手记显示独立生活状态卡：实际住户人数、建筑完整度细条和空置状态。单击有地面物资的土地可查看精确库存，世界中的物资堆同步反映数量档和取空。这些信息来自当前世界，不生成住房委托或发展目标。

住房与物资所在格优先显示土地页；住房卡支持转入建筑近景和打开住户档案。施工中显示进度，空地不会保留空的住房卡背景。人物档案中的镜头操作继续独立使用。

现场页将所选土地的水分、肥沃度与活动压实显示为三组分色读数和细条，数值直接读取当前土地。地面库存使用独立物资卡，仅显示存在的食物、木材、石料或铁矿；数量与世界物资模型来自同一库存记录。

天气与日间进度驱动光照和雾气。地表采样保留近远景层次，水面有细波纹；火灾、疾病和人物行为有视觉反馈。房屋、人物、动物与植被使用实际 3D 网格，详见 [模型系统](../development/models.md)与[美术资源](../development/assets.md)。

当前地表与建筑表面使用扫描材质：陡坡显露岩面，岸线过渡为湿泥，河水颜色读取河床深浅；草木位置和大小带有稳定差异。住房石基随坡地采样贴合。这些显示规则不修改寻路和经济参数，也没有加入任务流程；详细机制见 [地形与活动痕迹](terrain-and-traces.md)。

顶部各读数下方的小折线保留最近 32 次实际数值变化，按各自范围缩放；它表示变化方向，不是固定时间间隔或可直接比较的增长率。生成新世界、载入存档或回到实验起点都会清空旧折线，避免把不同世界和回溯前后的数值连成假趋势。

顶部资源栏统计居民携带、地面物资堆和仓库，排除未采集的地表资源。总量不代表每位居民都能到达相应物资。
