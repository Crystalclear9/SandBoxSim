# 世界系统

模拟以时间、土地、资源和自主居民组成。玩家直接改变条件，系统产生相互作用；没有必须完成的任务或固定发展顺序。

## 水土与资源

地块记录地形、高度、湿度、肥力、植被、压实、火情和资源节点。资源节点是未采集的地表存量；居民背包、地面物资堆和仓库分别保存已取得的物资。地表恢复、采集、生产和天气决定数量变化，矿石不通过自然生长恢复。

河流与水域影响饮水、地形和道路。湿地与泉眼涵养土壤，不能直接替代饮用水。道路改变通行，森林提供木材与栖息环境；火、旱季与动物活动影响区域状态。

## 居民与聚落

居民依照需求、效用、职业、性格、关系及可达性决定行动。他们会采集、饮水、睡眠、建造、耕作、贸易和形成家庭。材料不足、路径不通或身体需求变化会影响选择；玩家不需要通过委托安排住宅。

住房、仓库、农田和矿场使用内核施工与生产规则。外观变体、路向和模型细节只影响表现。社会历史保存人物身份、关系与聚落变化，死亡后的档案仍可观察。

## 荒野与动物

自然地点作用于真实土地：野果与花甸随周期结果，泉眼与苇泽保持水土，古树林影响湿度，倒木留下有限材料。取走物料、烧毁或改造会改变作用，不会触发任务或奖励领取。

食草动物活动与植被、水域和威胁相关；狼参与捕食。动物、资源和居民共享世界，具体地点机制见 [自由探索](exploration.md)。

## 时间与保存

内核按 tick 推进。图形会话另在每个日界处理荒野自然作用；Console 只运行内核。高倍速仍处理每个日界。

保存包含实际世界状态、随机流以及荒野地点、命名手记和人物关注。旧委托、工程、试炼和蓝图元数据不会续跑；已经形成的地形、建筑与资源保留。技术契约见 [存档](../development/saving.md)。
