# SandBoxSim · 玩家手册

游戏围绕自由观察、改变世界与自主居民展开。没有住房委托、工程阶段、蓝图目标、试炼、干预额度或指定发展路线。玩家可以直接改变地貌、添加生命、调整资源与天气，居民依照实际条件自行建造、生产、迁徙和形成关系。

底部“视角与操作”可展开全景、斜视、俯视、近景与鼠标说明；点击外部收起，Esc 收起并返回入口焦点。角度和距离始终可见，跟随当前居民时按钮显示“停止跟随”。暂停按钮变为“继续”，点击恢复原倍率。

## 鼠标与时间

| 操作 | 用途 |
|---|---|
| 观察模式左键拖动 | 平移地图 |
| 右键拖动 | 旋转与调整俯仰 |
| 滚轮 | 围绕鼠标指向的地面拉近、拉远 |
| 中键或 Alt＋左键拖动 | 任意工具模式下平移 |
| Shift＋滚轮 | 调整常规笔刷半径；生态工具保持固定范围 |
| 单击 | 直接选中画面中的人物、动物；空地查看土地，工具模式施加工具 |
| 观察模式双击 | 查看对象并把镜头移近 |
| Esc | 返回观察 |
| 空格 | 暂停、恢复暂停前的倍率 |
| F | 返回全景 |
| F10 | 进入／退出沉浸观察；沉浸时 Esc 也可返回 |

观察模式下，悬停人物或动物显示简短信息；建筑的实际表面会遮挡人物点选，门廊等空隙仍可透过。单击可见的屋顶或墙面会选择该建筑，避免选到建筑后方的地块。左键拖动不会顺便触发选择；按右键、中键或滚轮导航会中止当前画笔手势，移入界面时停止施加，重新回到地图不会隔着面板连画。快速拖动画笔会补齐经过的格子，范围环沿当前地面起伏显示。鼠标移动还会核对实际按键状态，即使系统漏发释放事件也会停止已松开的拖拽或画笔；窗口失焦、地图隐藏与世界载入/重建会清除当前手势，下一次操作需重新按下。

顶部“沉浸”隐藏界面，保留鼠标视角与空格暂停；点击角落返回按钮或使用 F10 / Esc 返回后保留原手记，Ctrl / ⌘ K 可直接恢复界面并搜索工具。

底部时间按钮控制倍率。暂停仍可移动镜头、观察或直接改变世界；人物与生态的模拟变化随时间推进。镜头不使用方向键、WASD 或 Q/E。

人物交谈使用张手、点头与视线转移，采集、分享和进食仍由实际动作状态驱动。镜头靠近时可观察鞋底的坡面补偿；暂停同时停止角色位置、转向与关节变化。

## 自由工具

底部“创造”展开左侧工具库；搜索跨全部分类查找名称和用途，切换分类清空搜索。左侧固定生命、生态、地貌、资源、灾害和祝福分类。Ctrl / ⌘ K 聚焦搜索，Enter 选择首个结果，向下键进入列表；搜索框中 Esc 先清空非空查询，空查询时退出。单列工具保留名称、用途与选中勾号，列表可滚动，当前工具参数固定在同一面板下方。常规工具可通过拖动条或数值框调整作用范围与强度，两种方式同步；生态工具每次栽植一片影响周围三格的地块，可连续栽植。地貌工具包含草地、河流、山地、沙地、湿地、雪地、旱地、熔岩、农田和道路，以及升降地形、移除水域。

资源工具改变真实地表节点；居民仍需要采集和可达路径。湿润土壤不等于饮水，农田地形也不同于居民建造的农业建筑。这些是模拟中的自然关系，不是玩家必须完成的步骤。

打开手记会结束当前干预；Esc 或工具库关闭按钮返回观察。左上角切换场景会先显示替换确认，取消保留当前世界；需要保留的进展应先保存。

工具库保留最近四种选用工具。大窗口在搜索框下方显示快捷条，小窗口使用标题旁的“最近”菜单；点击即可切回对应工具与分类，沿用原参数。快捷条复用时保持位置，重新打开后按最近顺序排列。记录只保留在当前运行会话。

世界设置提供天气、世界规则、图层、保存、载入和实验回溯。可以开启和平、高出生、禁止死亡等规则，也可以让自然变化继续发生。

## 自由栽植

“生态”提供花种、野果、苇泽与腐木。适宜水土下，植物约八天逐步成形；干旱会使成熟度停滞或回退，踩踏会减慢恢复。附近成熟且湿润的花甸为野果授粉，增加四分之一的额外结果。苇泽涵养周围土壤；新放置腐木带有有限的 24 单位木料，留在原地育土或被居民取走。

栽植保留已有地形高度、道路与建筑；不会凭空增加居民库存。可以把不同生态并置，观察季节、动物、采集和火灾的连锁变化。新地块与成熟度随世界保存。

## 世界手记

再次点击“创造”收起工具库会同时结束当前画笔，避免隐藏工具后误画地图。

控制栏、工具库与手记统一使用岩灰底色、暖灰白文字、苔灰分组与旧铜色强调，当前倍率、工具与手记入口以底色及细线标识；顶部和底部的手记入口保持同步。人物页把可点击的缩略肖像与姓名、身份和真实行为并排，需求与物资接在下方；小图不堆放工作室工具栏。观察窗使用相同的自然深色底与分色需求条，危险时转为暖红；名称和百分比仍保留，不需要仅靠颜色识别状态。

点击整张居民肖像或其“近看居民 ↗”文字，可打开独立观察窗；Tab 聚焦后也可按 Enter／空格。底部工具栏按观察范围、角度和镜头分组，提供面部、手部、全身聚焦，以及正面、三刻、背面、拉远、拉近和复位；双击画面也可复位。顶部上一位（‹）与下一位（›）按稳定身份顺序切换存活居民，无须退出到地图重新点选。右侧同步显示真实行动、身体需求与可展开物资；下方跟随与关注按钮固定显示。返回按钮、Esc 或点击窗外空白可回到当前居民的手记，保留视角并恢复仍可用的入口焦点。右侧物资开关、库存摘要和跟随按钮固定可达，展开物资会自动带出内容。滚轮按比例缩放，Shift＋滚轮精调，镜头组显示距离。小图与大窗复用同一模型视口。观察窗不会自动暂停世界，空格可以暂停或恢复。

手记只有现场、详情、历史和曲线。现场页显示当前地区、区域地图、自选地点和世界记录，不会推荐下一步任务。详情根据选择显示人物、动物或土地；地表数据来自实际状态。

观察窗顶部“居民名录”或 Ctrl / ⌘ F 可按姓名、职业、人生阶段查找居民。每页最多 64 人，搜索覆盖全部存活居民；打开时显示当前居民所在页。上下键浏览、Enter 确认，Esc 收起并返回入口，点击行也可直接切换。再次按查找快捷键保留并全选当前查询。没有结果时不会误选其他居民。

观察窗底部距离滑条与滚轮、加减按钮保持同步，左侧更近、右侧更远；滑条聚焦时可用左右键微调及 Home／End。点击“环视”可缓慢转看模型，再次点击“停止”、拖动、选角度或复位即可接管。换居民、关闭窗口、切出应用或关闭柔和界面动效也会停止；世界暂停时仍可观察，不改变模拟。

人物可以命名、关注或跟随。人物页分为概览、生活、决策，三个页面都保留相同的肖像与身份头部；页签与底部关注／改名操作固定在滚动区之外。概览查看需求和可展开物资，生活查看关系与历史，决策查看性格和实际效用。点击肖像近看后可旋转、缩放，用柔光／侧光检查表面，不改变世界光照或模拟规则。名称最多 24 字，旧历史保留当时的名字。

人物读数区分身体状态（越高越好）与生理需求（越低越好），并显示文字状态。打开当前实体详情会收起重复选择卡；新操作反馈仍短暂显示。改名时 Enter 保存、Esc 取消，换居民会取消未保存草稿；关闭观察窗后缩略图恢复面部，重新展开保留工作视角。

自然地点与季节作用见 [自由探索](exploration.md)，居民自主发展见 [聚落与居民](settlements.md)，天气和生态关系见 [生态变化](ecology.md)。

## 世界手记的阅读与导航

顶部世界信息、资源和菜单共用连续轻量背景，保留中间的地图视野。手记使用炭灰面板、暖白文字与旧铜选中强调；底部导航并列呈现图标与标签，左侧工具库按内容与窗口高度调整，列表可滚动，详情页图标随人物／土地选择变化，小地图嵌入现场页。按钮用底色和细线区分悬停／选中，现场页将居民故事与世界回声分区显示。上方标签切换现场、人物或土地、历史和曲线；关闭按钮只收起面板，不改变世界。小地图标出选中地点，悬停显示坐标与定位环，单击跳转；记录地点和故事链接可用于回访，关注居民后能追踪其状态。页面内容来自实际世界，没有要求完成的流程。界面动效可在世界设置中关闭。

## 土地上的活动痕迹

居民反复经过和采集活动会缓慢压实土地，损耗植被并留下轻微下陷；闲置后逐步恢复。变化会保存，也会影响资源和植被再生。详见 [地形与居民留下的痕迹](terrain-and-traces.md)。
