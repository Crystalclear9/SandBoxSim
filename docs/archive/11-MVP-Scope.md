# 11 — MVP 范围与开发边界

项目目标是让少量居民产生可观察、可解释的生活变化。当前已推进到 M4/M5 核心及 M6–M8 的部分实现，尚未完成全部计划。详见 [本次核验](17-ImplementationAudit.md)。

| 分类 | 内容 | 当前情况 |
|---|---|---|
| 必须做：模拟基础 | 世界/资源/需求/Utility AI/寻路/固定 Tick | 已实现 |
| 必须做：建造与共享 | 住房/农田建筑/仓库/共享库存 | 已实现；本次修复仓库容量与农田维护 |
| 必须做：人口闭环 | 农业/出生/住房和食物约束/儿童阶段 | 已实现核心 |
| 必须做：玩家实验 | 放置居民、改条件、灾害、保存读取 | 已有工具面板与存档，部分灾害简化 |
| 必须做：基本聚落 | 长期共居、稳定住所、共享仓库形成村庄 | 已有形成/衰亡；多种子可靠性和归属联动未完成 |
| 可以做 | 更多热力图、实验对照、观察信息改进 | 优先补能解释模拟的工具 |
| 后续做 | 完整家庭展示、实际贸易、文明、外交 | 关系和个体冲突已有；其余未交付 |
| 暂时不做 | 完整科技树、金融、宗教、复杂装备、超大地图、联机、3D 美术 | 控制第一阶段规模 |

验收必须同时检查“10–30 个 NPC 自己生活”与“改变一个条件会影响多个系统”。
现阶段已有生存、资源枯竭、迁移、建造、出生、农业及火灾的场景测试；不能用单场景通过替代多种子或长期可玩性验收。

每个新机制进入开发前，说明读取/修改哪些数据、如何调试，以及增加涌现性、玩家能动性或观察价值中的哪一项。
阶段细目和验收判据见 [里程碑](12-Milestones.md)。
