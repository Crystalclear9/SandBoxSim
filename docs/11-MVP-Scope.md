# 11 — MVP 范围与开发边界

项目目标是让少量居民产生可观察、可解释的生活变化。任务书要求按阶段交付；当前为 M3 原型，尚未完成完整 MVP。

| 分类 | 内容 | 当前情况 |
|---|---|---|
| 必须做：模拟基础 | 世界/资源/需求/Utility AI/寻路/固定 Tick | 已实现 |
| 必须做：建造与共享 | 住房/农田建筑/仓库/共享库存 | 已实现；农田未生产 |
| 必须做：人口闭环 | 农业/出生/住房和食物约束/儿童阶段 | M4 待实现 |
| 必须做：玩家实验 | 放置居民、改条件、灾害、保存读取 | 已有部分 Core 干预接口；完整工具与存档待 M5 |
| 必须做：基本聚落 | 长期共居、稳定住所、共享仓库形成村庄 | 正式聚落实体待 M7；目前只有局部建造和迁移 |
| 可以做 | 更多热力图、实验对照、观察信息改进 | 优先补能解释模拟的工具 |
| 后续做 | 家庭、关系、贸易、文明、冲突 | M6–M8，不能标为当前功能 |
| 暂时不做 | 完整科技树、金融、宗教、复杂装备、超大地图、联机、3D 美术 | 控制第一阶段规模 |

验收必须同时检查“10–30 个 NPC 自己生活”与“改变一个条件会影响多个系统”。
现阶段可验收生存、资源枯竭、迁移、建造；出生、农业和火灾传播的因果链尚不能验收。

每个新机制进入开发前，说明读取/修改哪些数据、如何调试，以及增加涌现性、玩家能动性或观察价值中的哪一项。
阶段细目和验收判据见 [里程碑](12-Milestones.md)。
