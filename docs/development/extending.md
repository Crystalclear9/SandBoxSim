# 扩展世界内容

客户端以自由探索为默认体验，新增内容应通过地貌、资源、居民与生态关系呈现，不增加任务入口、发展路线或奖励清单。

## 自然地点

`Core/Systems/WildPlaces.cs` 定义地点类型、确定性分布、日界作用与元数据编码。新增类型需要补齐名称、地形初始化、有效条件、真实作用和描述，并保持既有枚举值稳定。

`Godot/NatureModels.WildPlaces.cs` 为每种地点提供实际模型。季节、地形和物资状态决定外观，观察不能生成资源或推进时间。旧档缺少新地点时保留原地理，不自动插入地点。

## 模型与界面

网格及材质入口见 [3D 模型系统](models.md)。主界面在 `MainGame.Interface.cs`，田野手记的阅读样式在 `MainGame.Notebook.cs`。使用非交互装饰层、统一字体间距与实际状态；新工具直接改变世界，不引入积分或工程流程。

## 验证与保存

扩展地点需要覆盖确定性、观察纯度、条件变化、资源有限性和保存后的继续运行。客户端自检检查输入、布局、模型和旧任务字段的忽略行为；当前存档契约见 [保存](saving.md)。
