## 修复内容与系统连接

| 系统 | 问题与修复 | 读取 / 修改 / 连接 |
|---|---|---|
| 采集与建造 | 住房数量饱和误停仓库材料采集；仓库造价超过携带舒适量；木石库存误压制缺粮者采食。独立计算仓库需求，预留必要建材，食物抑制只读食物库存 | 读取人口、计划床位、建筑容量、三层库存；改变 Utility 分数，连接采集、建造与生存 |
| 建造选址与执行 | 材料评估位置和扣料位置不同；最近空地没材料就停止搜索；多人重复开工。选择可供料工地，计入在建床位和仓库，执行前再查需求 | 读取工地附近物资；开工时扣料和增加建筑，材料不足时事务不落地 |
| 聚落空间识别 | 相邻网格强行合并独立居民群；全群质心漂移反复清零共处天数。以完工共享仓库作空间锚点，半径内居民归入最近一个锚点，近邻设施合并 | 读取已完工设施和实际居民位置；修改候选和聚落记录，不生成居民、设施或资源 |
| 聚落持续性与解散 | 多群共用单候选；间隔前天数被继续累加；居民迁离后永久残留幽灵聚落。候选独立持久化，要求连续日评估，一对一匹配身份，无居民按原阈值解散 | 连接每日 Tick、事件记录、人口统计、存档和摘要 |
| 存档确定性 | 地面资源增量浮点缓存与读档重算不一致；等距料堆/仓库受存活列表交换影响。规范槽位顺序重算总量和选取等距目标；释放微量残余时失效缓存 | 修改派生缓存与选靶顺序，保留真实物资转移；候选列表及最后评估 tick 随存档保存 |
| 气候 | 长期天气增量累计把温度压至零。每小时向环境温度恢复，默认速率 0.05；连续雪天稳定降温，转晴后恢复 | 读取天气和温度基线，修改 Tile 温度，连接蒸发、资源与火险 |
| 火灾 | 扫描中刚点燃的格子同次继续传播；蔓延数量和上限计算过期；自然点燃绕过上限。固定本次蔓延源，逐格更新数量并检查上限 | 读取当前火情，修改火状态、观测计数和 Fire 随机流 |

这些修改允许“材料可达 → 正常开工 → 共享设施 → 持续共同生活 → 自然形成聚落”发生，仍允许资源不足、居民离开与聚落解散。没有创建城市按钮，也没有固定每个种子的结果。

## 回归测试与验收口径

新增 `M7RepairTests` 和 `WorldRepairTests` 共 19 项，覆盖材料需求、扣料事务、重复开工、独立候选、共享设施附近活动、相邻网格独立群、真实人口滞回、幽灵聚落、候选存档、火灾上限、温度恢复与库存确定性。

修正四类过期测试前提：施工完工测试单独推进 BuildingSystem，避免 AI 开另一块田污染结果；PeaceMode 按已生效规则测试存档记录与相同配置恢复；社交检测真实关系记录峰值，允许后续遗忘或死亡清理；聚落形成检测实际活跃峰值，允许居民后来离开。

M7 批量种子、初始人口、持续天数、成立阈值和验收门槛均未改变：20 种子 × 200 天，100×100 地图，初始 40 人；至少 15/20 在 150 天内成立，至少 5/20 在 200 天内曾同时有两个活跃聚落。气候恢复是上述缺陷修复，配置新增参数已同步 JSON 与参数表。
